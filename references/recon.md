# 行业侦察

给诊断和素材生产提供弹药。**目标不是拿到全量数据，是拿到 10–20 条
能说明问题的素材。** 提案不需要大数据，需要说得准。

---

## 数据源纪律（红线）

**任何情况下不得用登录态爬取小红书 / 抖音 / 任何内容平台。**
蔡蔡实测账号被封 7 天。这条没有例外，没有"小心一点就行"。

按优先级取料，**只准往下走，不准跳级**：

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 蔡蔡 / 客户手动提供 | 截图、链接、粘贴文案。最可靠，10–20 条足够 |
| 2 | 公开检索 | 行业投放分析、案例复盘、**以及客户自己的公开账号与官网** |
| 3 | 官方合规工具 | 巨量创意等。投放素材本身即公开广告，取用合规 |
| 4 | 付费情报平台 | 千瓜 / 新红 / 广大大 / App Growing。**验证出付费行业后再买** |

冷启动只用 1 + 2。

### 检索手段（WebSearch 坏了不是借口）

WebSearch 在某些环境不可用。**这时候用浏览器，不要直接跳过检索**：

```
mcp__Claude_Browser__preview_start  {"url": "https://www.bing.com/search?q=<关键词>"}
mcp__Claude_Browser__get_page_text
```

### 先查客户，再查行业

**顺序不能反。** 行业情报到处都有，客户情报只有一份。

- 查到了客户的公开账号/官网 → 打开读，诊断直接升到 A 级（他们的内容 vs 赛道跑量内容）
- **查不到** → 明确告诉蔡蔡"这个项目公开网络上没有声量"，
  然后回到第 1 优先级问他。**查不到本身就是情报**，
  对招募型项目尤其重要——没声量本身可能就是最大的缺口
- **无论如何不许编。** 没看过客户的内容，就不能写"你们的内容在讲 X"。
  这条比数据源纪律更重要：数据源违规是风险，编造客户现状是当场露馅

## 最少可用样本

| 样本量 | 能做到 |
|---|---|
| 0 条 | 只能出 C/D 级诊断，锐度低但**仍然可以跑**——不要因为没料就停 |
| 5–10 条 | 能出 B 级诊断，够快档用 |
| 15–20 条 | 够全档用，钩子公式库能立起来 |
| 20 条以上 | 边际收益递减，别花时间刷量 |

**零材料也必须能出货。** 这是本 skill 的基本要求——
陌生客户不会先给你材料，你得先给他东西。

---

## 向客户要材料的话术

陌生客户没有理由配合你。所以**顺序是先给再要**。

### 最优：不要材料，直接给

> "我按公开能看到的先做了一版你们赛道的诊断，你看准不准。"

这是最强的开场：零门槛、不索取、而且所有人都想知道"关于我的判断准不准"。
客户如果回你一句"这条不对，我们其实是……"——**你就免费拿到 A 级材料了。**

### 次优：低门槛索要

要具体的、少量的、他愿意 show 的：

- ✓ "你们最近效果最好的 3 条素材能发我看看吗"（他愿意 show 好的）
- ✓ "你们现在主要投哪个平台"（一句话能答）
- ✗ "把你们的投放数据发我"（涉密，不会给，还显得你很冒失）
- ✗ "填一下这个 brief 表"（陌生阶段没人填表）

### 记住

**要不到材料不是失败。** 要不到就用公开检索出 B/C 级诊断照样发，
诊断本身就是索要材料最好的钩子。

## 侦察产出

侦察完必须能回答这七个问题，答不上就是没侦察完：

1. 这个行业当前跑量素材的**前 3 秒**在说什么？（钩子结构）
2. 客户真正怕什么？（焦虑源，不是他嘴上说的）
3. 用什么换联系方式？（诱饵形态）
4. 靠什么建立信任？（背书范式）
5. 不能说什么？（合规红线）
6. **考核什么？留资成本还是 ROI？**（断层线，决定引擎口径）
7. 目标客户的素材，跟上面这些差在哪？（→ 直接喂给诊断层）

前 6 条落进 `industries/<行业名>.md`，第 7 条落进诊断。

## 行业包的复用与更新

- 先查 `industries/`，有包直接加载，**不要重复侦察**（这是"跑得越多越快"的来源）
- 包里标了生成日期。超过 90 天的包，钩子公式库要重新抽样验证——
  素材公式会过季
- 更新包时**只增不删**，旧公式标注"<日期>已降温"而不是删掉，
  因为公式会轮回
